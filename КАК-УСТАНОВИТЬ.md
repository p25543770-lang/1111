# Как загрузить сохранения Mindustry

Готовый архив: **`mindustry-saves-import.zip`** (4.5 МБ, 45 сохранений + 45 бэкапов + 2 карты + настройки).
Пересобрать архив после добавления новых файлов: `python3 make-import-zip.py`

Структура внутри архива — такая же, как делает сама игра при экспорте
(Настройки → Данные → Экспорт), пути считаются от папки данных Mindustry:

```
settings.bin          <- файл настроек (обязателен, иначе игра скажет "Not valid save data")
settings_backup.bin
server_list.json
maps/                 <- кастомные карты (7.msav, 12.msav)
saves/                <- все сохранения (*.msav и *.msav-backup.msav)
```

## Способ 1 — через саму игру (рекомендуется)

1. Запустить Mindustry, выйти в главное меню.
2. **Настройки → Данные (Data) → Импорт (Import)**.
3. Выбрать `mindustry-saves-import.zip` и подтвердить.

Игра сама удалит текущие сохранения/кеш, распакует архив в свою папку данных
и перезагрузит настройки. После этого сохранения появятся в меню «Играть → Сохранения».

> ⚠️ Импорт заменяет текущие сохранения и настройки. Если в игре есть что-то нужное —
> сначала сделай экспорт текущих данных.

## Способ 2 — вручную (ничего не удаляется)

Закрыть игру и распаковать архив **в папку данных Mindustry** (с заменой файлов):

| Платформа | Папка данных |
|---|---|
| Windows (Steam, portable) | `<Steam>\steamapps\common\Mindustry\saves\` |
| Windows (обычная версия) | `%appdata%\Mindustry\` |
| Linux | `~/.local/share/Mindustry/` |
| macOS | `~/Library/Application Support/Mindustry/` |
| Android | `Android/data/io.anuke.mindustry/files/` |

Проверить нужную папку просто: там уже лежат файлы `settings.bin`, `server_list.json`
и папка `maps` — из этого же набора собраны файлы в архиве.

После распаковки должно получиться так:

```
<папка данных>/settings.bin
<папка данных>/saves/0.msav
<папка данных>/saves/0.msav-backup.msav
<папка данных>/saves/sector-serpulo-111.msav
...
```

## Что внутри

* 45 сохранений (кампания Серпуло и обычные карты) для build 158–160 — текущая игра 160.5 их откроет, более новые версии подтягивают старые сейвы.
* Парные файлы `*-backup.msav` — это автоматические бэкапы предыдущего состояния сейва;
  игра их не показывает в списке, но именно из них восстанавливается сейв, если основной файл повреждён. Можно удалить — не обязательно.
* Превью сохранений (`previews/`) в архиве нет — игра сгенерирует их сама при первом открытии списка сохранений.
* `maps/steam_autocloud.vdf` в архив **не** включён: это служебный маркер Steam Cloud с чужим `accountid`, Steam создаёт его сам.

## Почему экспорт из игры не сработал

В `last_log.txt` 117 ошибок вида:

```
[E] Failed to read schematic from file 'saves/schematics/...msch'
[E] arc.util.ArcRuntimeException: File not found: saves/schematics/...msch (local)
...
[E] arc.util.ArcRuntimeException: File not found: saves/schematics/..3.msch (local)
    at mindustry.ui.dialogs.SettingsMenuDialog.exportData(SettingsMenuDialog.java:601)
```

Экспорт в игре падает не из-за сохранений, а из-за схем (`.msch`) с русскими
названиями: файлы лежат на диске, но при чтении путь ломается (кодировка), и
`exportData` обрывается с исключением — поэтому архив получался пустым/не создавался.
Этот zip собран в обход `exportData`, поэтому проблема не мешает.

Если хочешь, чтобы экспорт работал и дальше — проще всего убрать из папки
`schematics` файлы с не-латинскими именами (латиница + пробелы работают нормально),
либо переименовать их в латиницу.
