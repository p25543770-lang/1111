# Как загрузить сохранения Mindustry

Все файлы Mindustry из этого репозитория уже собраны в архив **`mindustry-saves-import.zip`** (4.5 МБ).
Он готов к импорту: Настройки → Данные → Импорт → выбрать zip.

Пересобрать архив после добавления новых файлов: `python3 make-import-zip.py`

## Что уже внутри архива

| В архиве | Куда попадёт в игре | Файлов |
|---|---|---|
| `settings.bin` | `<папка данных>/settings.bin` (настройки, прогресс исследований/кампании) | 1 |
| `settings_backup.bin` | `<папка данных>/settings_backup.bin` | 1 |
| `server_list.json` | `<папка данных>/server_list.json` | 1 |
| `saves/*.msav` | `<папка данных>/saves/` | 90 (45 сохранений + 45 бэкапов) |
| `maps/*.msav` | `<папка данных>/maps/` (кастомные карты `7`, `12`) | 2 |

## Чего в архиве нет (и почему)

Этих файлов **нет в репозитории**, поэтому в zip они не попали — но игра без них полностью работоспособна:

| Нет | Что это | Нужно ли |
|---|---|---|
| `schematics/*.msch` | схемы построек (у тебя их ~117, с русскими именами) | нет, но если нужны — см. ниже |
| `mods/*.jar` / `*.zip` | моды | нет, если играешь без модов |
| `previews/*.png` | картинки-превью в списке сохранений | нет — игра сама нарисует их при первом открытии списка |
| `assetCache/` | кеш картинок из сейвов с внешними ассетами | только если в сейве были свои картинки/текстуры |
| `screenshots/`, `be_builds/` | скриншоты и блюпринты | нет |
| `last_log.txt`, `steam_autocloud.vdf` | лог игры и маркер Steam Cloud | нет (второй привязан к аккаунту, Steam создаёт сам) |

## Как получить ПОЛНЫЙ архив (включая схемы, моды, превью)

Два варианта:

**А. Собрать у себя на ПК (быстрее и полнее — включает всё, что есть в игре):**

1. Скачай из репозитория `build-full-zip.ps1` и `build-full-zip.bat` — положи в одну папку.
2. Двойной клик по **`build-full-zip.bat`**.

Скрипт сам найдёт папку данных Mindustry (в т.ч. Steam-овскую), покажет, что в ней есть,
и соберёт `Mindustry-Data-<дата>.zip` на рабочем столе — этот архив можно сразу загрузить
через Настройки → Данные → Импорт.

Полезные ключи:
```
build-full-zip.bat -DataDir "D:\Steam\steamapps\common\Mindustry\saves"   # указать папку вручную
build-full-zip.bat -Out "D:\Mindustry-Data.zip"                           # куда положить архив
build-full-zip.bat -FixSchematics                                         # переименовать схемы в латиницу
```
`-FixSchematics` лечит ту самую проблему из `last_log.txt`: схемам с русскими именами
транслитом даются латинские имена (`Схема обороны 02.msch` → `Shema oborony 02.msch`),
после чего и загрузка схем, и встроенный экспорт игры перестают падать.

**Б. Загрузить недостающие файлы сюда, в репозиторий** (папки `schematics`, `mods`, `previews`),
и я пересоберу `mindustry-saves-import.zip` уже вместе с ними.

> Внимание про схемы: у тебя в логе 117 ошибок `Failed to read schematic from file 'saves/schematics/...msch'`,
> и из-за них падает встроенный экспорт игры (`SettingsMenuDialog.exportData`). Файлы на диске есть,
> но игра не может их прочитать из-за не-латинских имён. На работу сохранений это не влияет,
> но если хочется починить — `-FixSchematics` или переименовать схемы в латиницу руками.

## Способ 1 — импорт через саму игру (для готового zip)

1. Запустить Mindustry, выйти в главное меню.
2. **Настройки → Данные (Data) → Импорт (Import)**.
3. Выбрать zip и подтвердить.

Игра сама удалит текущие сохранения и кеш, распакует архив в папку данных и перечитает настройки.
Сохранения появятся в «Играть → Сохранения».

> ⚠️ Импорт заменяет текущие сохранения и настройки. Если в игре есть нужное — сначала сделай экспорт.

## Способ 2 — вручную (ничего не удаляется)

Закрыть игру и распаковать архив **в папку данных Mindustry** (с заменой файлов):

| Платформа | Папка данных |
|---|---|
| Windows (Steam) | `<Steam>\steamapps\common\Mindustry\saves\` |
| Windows (обычная версия) | `%appdata%\Mindustry\` |
| Linux | `~/.local/share/Mindustry/` |
| macOS | `~/Library/Application Support/Mindustry/` |
| Android | `Android/data/io.anuke.mindustry/files/` |

Ориентир: там уже лежат `settings.bin`, `server_list.json` и папки `maps`, `saves`, `schematics`.

```
<папка данных>/settings.bin
<папка данных>/saves/0.msav
<папка данных>/saves/0.msav-backup.msav
<папка данных>/saves/sector-serpulo-111.msav
...
```

## Мелочи, о которых стоит знать

* Парные файлы `*-backup.msav` — автобэкапы предыдущего состояния сейва (игра их в списке не показывает,
  но восстанавливает сейв из них, если основной файл повреждён). Можно удалять без последствий.
* Есть 6 сейвов, у которых сохранился только бэкап без основного файла
  (`3`, `19`, `sector-serpulo-127`, `sector-serpulo-204`, `sector-serpulo-86`, `sector-serpulo-97`).
  В списке сохранений игры они не появятся — при необходимости переименуй
  `X.msav-backup.msav` в `X.msav`, и сейв станет виден.
* Сейвы сделаны в build 158–160, текущая игра 160.5 (v8) их открывает.
