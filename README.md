# АвтоВвод

Приложение открывает нужный сайт и **по очереди вводит данные из списка** в заданные поля,
а затем нажимает кнопку (например, «Отправить»). Поля выбираются мышкой прямо на странице —
программировать ничего не нужно.

## Что умеет

| | |
|---|---|
| **Список данных** | вставка из Excel / Google Таблиц, файлы CSV, TSV, TXT, XLSX (UTF-8 и Windows-1251) |
| **Выбор полей** | клик по полю на странице → готовый селектор, без возни с кодом |
| **Действия** | ввод текста, печать по буквам, клик, выбор в списке, галочка, клавиша, загрузка файла, пауза, ожидание элемента |
| **Значение** | из колонки таблицы, свой текст для всех строк, шаблон `{{Имя}} — {{Город}}` |
| **Запуск** | по очереди по всем строкам, с паузами, повторами, стартом с любой строки, остановкой в любой момент |
| **Повтор** | повтор до изменения страницы или ИИ-агент, который сам решает, что делать после попытки |
| **Контроль** | журнал по каждому шагу, прогресс, снимок экрана при ошибке |
| **Сохранение** | наборы настроек в файлы, автовосстановление последней настройки |

## Повтор до изменения страницы

Если сайт принимает данные не с первого раза (например, «Очистить» → ввести заново →
«Отправить»), включите в разделе **«Шаги» → «Повтор до изменения»**:

1. Первым шагом добавьте **клик по кнопке очистки**.
2. Дальше — ввод полей и клик по кнопке отправки/сохранения.
3. Включите «повторять, пока страница не изменится», задайте число попыток (по умолчанию 5),
   задержку проверки (1500 мс) и, при желании, селектор элемента, который должен измениться
   (например, блок с результатом).
4. Галочка «остановиться, когда изменилось» завершает **весь запуск**, как только страница
   отреагировала.

Проверка идёт по URL и тексту страницы (или выбранного элемента). Если изменений нет — строка
повторяется; если изменение появилось — журнал пишет «страница изменилась на попытке N — готово»,
и выполнение останавливается. Если за все попытки ничего не изменилось — предупреждение
в журнале и переход к следующей строке.

То же самое можно включить из чата: «включи повтор, пока страница не изменится, и остановись
при изменении» или кнопкой «Повтор до изменения» в разделе «ИИ».

## ИИ-агент

Режим, в котором приложение не просто повторяет сценарий, а после каждой попытки спрашивает
локальную модель, что делать дальше. Агент получает адрес, заголовок, видимый текст страницы и
список кнопок/полей — и выбирает одно решение:

| Решение | Что делает приложение |
| --- | --- |
| `next` | результат достигнут — переходит к следующей строке |
| `repeat` | повторяет шаги ввода |
| `clear` | нажимает кнопку очистки (по селектору или по тексту) и повторяет ввод |
| `submit` | нажимает кнопку отправки ещё раз, без повторного ввода |
| `reload` | перезагружает страницу и повторяет ввод |
| `stop` | останавливает весь запуск |
| `fail` | строка не поддалась — идёт дальше |

Включение: **«03 Шаги» → «Параметры запуска» → «ИИ-агент» → «вести ввод агентом»**.
«Попыток» — сколько раз пробовать одну строку (1–20), «Ждать, мс» — пауза перед оценкой страницы,
«Цель» — словами, чего нужно добиться (уходит в подсказку агенту, например «заявка должна
появиться в списке»).

Решения и причина пишутся в журнал: `ИИ (2/4): очистить и повторить — на странице ошибка`.
Если у модели нет ответа, агент продолжает работать на встроенных правилах: страница изменилась
без слов об ошибке — успех; на странице ошибка — очистка и повтор; изменений нет — очистка,
повтор, перезагрузка, повторная отправка, затем переход к следующей строке.

«Повтор до изменения» и «ИИ-агент» взаимоисключающие: попытки ведёт что-то одно, включение
одного снимает другой. Из чата: «включи ИИ-агента, пусть сам решает» или кнопка «ИИ-агент».

## Локальный ИИ-ассистент

В приложении есть чат (раздел **05 «ИИ»**), который работает **только на вашем компьютере**:

* подключается к локальной модели — Ollama на `127.0.0.1:11434` или любому
  OpenAI-совместимому серверу (LM Studio, llama.cpp);
* если модели нет — включается встроенный офлайн-режим: он понимает команды
  и работает без интернета и без установки чего-либо;
* ассистент не только отвечает, но и **управляет приложением**: подставляет адрес сайта,
  открывает его внутри приложения, разбирает вставленную таблицу, добавляет шаги,
  запускает и останавливает ввод, показывает состояние.

Подключить модель через Ollama:

```bash
ollama pull llama3.2
ollama serve
```

Приложение само найдёт её при открытии раздела «ИИ».

LM Studio или llama.cpp — включите локальный сервер и укажите адрес:

```bash
# Windows
set AUTOVVOD_AI_URL=http://127.0.0.1:1234

# macOS / Linux
export AUTOVVOD_AI_URL=http://127.0.0.1:1234
```

Необязательно: `AUTOVVOD_AI_MODEL=имя-модели` — какую модель использовать.

Никаких API-ключей и облачных запросов: обмен идёт по localhost.

## Установка вручную (если не пользуетесь run.bat / run.sh)

Нужен Python 3.9+ ([python.org](https://www.python.org/downloads/), при установке отметьте
«Add Python to PATH»).

```bash
pip install -r requirements.txt
playwright install chromium

```

Откроется браузер с адресом `http://127.0.0.1:8765` — это само приложение.

## Как пользоваться

### 1. Сайт

Впишите адрес страницы, которую нужно заполнять, и нажмите **«Открыть сайт»**.
Под кнопкой появится изображение страницы.

### 2. Выберите поля

Нажмите **«Выбирать поля на сайте»** и щёлкайте по полям на превью:

* по полю «Имя» → появится шаг `fill` (ввод текста);
* по выпадающему списку → шаг `select`;
* по галочке → шаг `check`;
* по кнопке «Отправить» → шаг `click`.

Каждый клик сразу превращается в шаг автоматизации. Колесо мыши прокручивает страницу.
Закончили — **«Закончить выбор»**. Порядок шагов можно менять стрелками ↑ ↓.

> Если у поля есть `id` или `name`, селектор получается коротким (`#name`, `input[name="phone"]`),
> а кнопка **«проверить»** у шага подсветит найденный элемент на странице.

### 3. Данные из списка

**Вставить из Excel** — скопируйте диапазон в Excel или Google Таблицах и вставьте в поле.
Первая строка должна содержать названия колонок. Или **Загрузить файл** (CSV / XLSX),
или **Ввести вручную**.

### 4. Сопоставьте колонки и поля

У каждого шага ввода выберите, **из какой колонки** брать значение. Можно просто щёлкнуть
по заголовку колонки в таблице — значение подставится в активный шаг.
Для одинакового текста во всех строках выберите «свой текст», для склейки — «шаблон»
(например `{{Фамилия}} {{Имя}}`).

### 5. Запуск

**«Запустить»** — приложение откроет сайт (по умолчанию без окна) и пройдёт по всем строкам.
В журнале видно каждый шаг; при сбое сохраняется снимок экрана в папку `screenshots/`.

Полезные переключатели:

* **без окна браузера** — снимите галочку, чтобы видеть, что происходит;
* **перезагружать страницу для каждой строки** — если после отправки форма «залипает»;
* **пауза после строки** — для сайтов с защитой от частых отправок (начните с 1000–3000 мс);
* **повторов на строку** — если одна и та же заявка нужна несколько раз;
* **начать со строки** — продолжить с места, где остановились.

## Как это работает

Playwright управляет настоящим Chromium: приложение ставит браузер, открывает страницу,
находит элементы по CSS-селекторам и выполняет действия по шагам для каждой строки таблицы.
Сервер локальный (FastAPI + uvicorn), интерфейс — обычная веб-страница.

```
app.py        запуск приложения и открытие интерфейса
server.py     локальный сервер: API данных, выбора полей и запуска
runner.py     движок: открывает сайт и вводит строки по очереди
picker.py     браузер для выбора полей и превью страницы
static/       интерфейс (HTML/CSS/JS)
demo/         демо-форма и пример списка
release/      готовый архив приложения (autovvod-1.0.zip)
configs/      сохранённые наборы настроек (создаётся автоматически)
screenshots/  снимки экрана при ошибках
```

## Частые вопросы

**«не удалось запустить браузер»** — выполните `playwright install chromium`.
В Linux иногда нужны системные библиотеки: `playwright install-deps chromium`.

**Поле не находится** — нажмите «проверить» у шага. Если селектор не подходит
(например, страница генерирует случайные `id`), выберите поле заново или впишите селектор
вручную: `input[name="phone"]`, `form#order button[type=submit]`. Отметьте шаг как
необязательный, если элемент появляется не всегда.

**Сайт ругается на робота / просит капчу** — увеличьте паузы между строками,
запускайте без галочки «без окна браузера». Капчу и вход по SMS автоматизация не обходит.

**Сайт очищает форму после «Отправить»** — так и должно быть; если нет, включите
«перезагружать страницу для каждой строки».

**Можно ли заполнять несколько разных сайтов?** — да, просто сохраните отдельные наборы
настроек кнопкой «Сохранить настройки» и переключайтесь через «Загрузить».
