# Подбор пароля — мини-проект на C++

Простая учебная демонстрация перебора **своего тестового пароля** в браузере. Приложение само запускает небольшой HTTP-сервер и не требует библиотек или интернета при работе. Оно сравнивает варианты с паролем, который вы сами ввели: это не средство доступа к сайтам, аккаунтам или файлам. Не вводите настоящие пароли.

## Windows: готовое приложение

Готовые файлы для 64-битной Windows 10/11: `release/password_demo.exe` и `release/start.bat`. Можно скачать архив `release/password_demo_windows.zip` и распаковать оба файла в одну папку.

Запустите `start.bat`: выберите 1 для доступа только с этого компьютера, 2 для устройств в доверенной сети или 3 для конкретного IPv4-адреса своего компьютера; затем укажите порт (по умолчанию 8000). В режиме 2 программа `ipconfig` покажет IPv4-адреса: передайте другому человеку адрес вида `http://192.168.1.10:8000/`, подставив свой IP. Если интерфейсов несколько, выберите адрес нужной сети. Оставьте окно приложения открытым; Ctrl+C останавливает сервер.

Можно также запустить сам `password_demo.exe` — без параметров он доступен только по адресу **http://localhost:8000/**.

## Windows: сборка EXE из исходников

Нужен компилятор C++17, например MinGW-w64 (g++) или Visual Studio с компонентом «Разработка классических приложений на C++» и CMake.

### Через CMake

В терминале в папке проекта:

```bat
cmake -S . -B build
cmake --build build --config Release
```

Запустите `build\Release\password_demo.exe` (для Visual Studio) или `build\password_demo.exe` (для некоторых других генераторов). Затем откройте **http://localhost:8000/**. Оставьте окно приложения открытым; Ctrl+C останавливает сервер.

### Через MinGW-w64 без CMake

```bat
g++ -std=c++17 -O2 src/main.cpp -o password_demo.exe -lws2_32
password_demo.exe
```

## Linux / macOS

```sh
g++ -std=c++17 -O2 src/main.cpp -o password_demo
./password_demo
```

Откройте **http://localhost:8000/**. Параметры запуска одинаковы для Windows и Linux:

- `password_demo.exe --port 8080` — другой порт.
- `password_demo.exe --public --port 8000` — слушать все IPv4-интерфейсы, в том числе локальную сеть.
- `password_demo.exe --host 192.168.1.10 --port 8000` — слушать только конкретный IPv4-адрес, уже назначенный этому компьютеру.

В Linux используйте `./password_demo` вместо `password_demo.exe`. Адрес `0.0.0.0` означает все интерфейсы; его нельзя использовать как адрес для отправки другому человеку.

## Как пользоваться

1. Введите выдуманный пароль, выберите набор символов и максимальную длину. Пароль должен состоять только из выбранных символов.
2. Нажмите «Начать подбор». Программа перебирает варианты от коротких к длинным, показывает количество попыток и время.
3. Для защиты от долгого выполнения установлен предел в 2 000 000 попыток; при его достижении пароль может остаться ненайденным.

## Ссылка для другого человека

`localhost` всегда обозначает **компьютер самого открывающего ссылку**, поэтому передать `http://localhost:8000/` другому человеку как общую ссылку нельзя. Для доступа в доверенной локальной сети используйте режим 2 в `start.bat` или параметр `--public`, узнайте IPv4 командой `ipconfig` в Windows и передайте ссылку с этим IP и выбранным портом. Может потребоваться разрешение входящих подключений в брандмауэре.

Если человек находится в другом месте, устройства можно объединить в доверенную частную VPN-сеть, например Tailscale, и использовать VPN-адрес компьютера вместо локального IP. VPN должна быть установлена и настроена на обоих устройствах, а брандмауэр — разрешать соединение. Сам по себе `--public` не создаёт общедоступную ссылку в интернете.

Это демонстрационный сервер без авторизации и шифрования: не открывайте его напрямую в интернет и не передавайте настоящие пароли.

## Бот для проверки защиты своего сайта (Windows)

Отдельный `release/site_bot_windows.zip` содержит `site_bot.exe`, `start_site_bot.bat` и инструкцию. Распакуйте архив и запустите `start_site_bot.bat`. Бот проверяет HTTPS POST-обработчик входа **вашего сайта или сайта, на проверку которого получено явное разрешение**, с помощью отдельного тестового аккаунта и заведомо неверного пароля. Пароль вводится скрыто (только ASCII), не сохраняется в файл и не должен быть настоящим.

Укажите URL обработчика, имена полей и формат тела (`form-urlencoded` или JSON). Бот отправит от 1 до 5 одинаковых запросов с паузой 2 секунды и остановится при HTTP 403, 429, ошибке сети или сервера. Он не подбирает пароли. Тест может привести к блокировке тестового аккаунта или IP; предварительно согласуйте проверку и изучите серверные журналы.

Результат — только HTTP-статусы. Они сами по себе не доказывают успешный вход или работу защиты: например, 403 может означать отсутствие CSRF-токена, а не блокировку перебора. Переадресации и cookies отключены. Формы, требующие CSRF, CAPTCHA, MFA, предварительную сессию или дополнительные поля, напрямую не поддерживаются. HTTPS-сертификат проверяется средствами Windows.

Для самостоятельной сборки в Visual Studio используйте обычные команды CMake выше (создаётся также `site_bot.exe`) либо компилятор MinGW-w64: `g++ -std=c++17 -O2 src/site_bot.cpp -o site_bot.exe -lwinhttp`.
