Бот проверки защиты входа для Windows 10/11 x64

Используйте только на своём сайте или с явного разрешения владельца.
1. Распакуйте архив полностью и запустите start_site_bot.bat.
2. Укажите HTTPS-адрес POST-обработчика входа (не обязательно адрес страницы).
3. Введите имена полей логина и пароля, логин отдельного тестового аккаунта
   и заведомо неверный тестовый пароль. Пароль вводится скрыто, только ASCII.
4. Выберите формат запроса: 1 — form-urlencoded, 2 — JSON.
5. Выберите 1–5 запросов и введите YES для подтверждения разрешения.

Бот отправляет только один и тот же заведомо неверный пароль, с паузой
2 секунды. Он не подбирает пароли. Останавливается при HTTP 403, 429,
ошибке сервера или сетевой ошибке. Проверка может временно заблокировать
тестовый аккаунт или IP — уточните настройки и проверьте журналы сайта.

Статус HTTP сам по себе не доказывает вход или наличие защиты: например,
403 может означать отсутствие CSRF-токена. Переадресации не выполняются,
cookie не сохраняются. Сайты, требующие CSRF, CAPTCHA, MFA, дополнительные
поля или предварительную сессию, этому простому боту не подходят.
HTTPS-сертификат проверяется средствами Windows. Не вводите реальные пароли.
