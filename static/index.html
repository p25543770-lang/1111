01 / САЙТ
БРАУЗЕР·ПРЕВЬЮ·ВЫБОР ПОЛЕЙ

ПОДКЛЮЧЕНИЕ К САЙТУ

Откройте страницу, которую нужно заполнять. Ниже появится её превью — по нему можно щёлкать мышкой и превращать поля в шаги автоматизации.

01

Адрес страницы

Нажмите «Открыть сайт» — ниже появится страница. Затем «Выбирать поля на сайте» и щёлкайте по полям прямо на превью: они станут шагами автоматизации. Колесо мыши прокручивает страницу.

02 / ДАННЫЕ
EXCEL·CSV / TSV / TXT·XLSX

ДАННЫЕ ИЗ СПИСКА

Вставьте таблицу из Excel или Google Таблиц, загрузите файл либо наберите строки вручную. Первая строка может быть названиями колонок.

01

Источник

Поддерживается вставка прямо из Excel/Google Таблиц (табуляция) и CSV с запятыми или ;.

CSV, TSV, TXT или XLSX. Кодировка определяется автоматически (UTF-8 / Windows-1251).

Можно не задавать колонки — вводите строки через запятую или табуляцию, колонки создадутся сами.

02

Таблица

щёлкните по заголовку колонки, чтобы выбрать её для шага
03 / ШАГИ
СЕЛЕКТОРЫ·ДЕЙСТВИЯ·ПАУЗЫ

СЦЕНАРИЙ ВВОДА

Каждый шаг — поле на сайте и значение из колонки таблицы. Порядок шагов совпадает с порядком действий браузера.

01

Шаги по строкам

Каждый шаг — это поле на сайте и значение из колонки таблицы. Порядок шагов = порядок действий браузера.

# Поле на сайте (селектор) Значение Откуда брать / текст Действие Пауза
Подготовительные шаги (выполняются один раз до первой строки)

Например: клик «Войти», ввод логина и пароля, переход на нужную страницу.

02

Параметры запуска

↻

Повтор до изменения

Сценарий «Очистить → ввести заново → нажать»: первым шагом поставьте клик по кнопке очистки, дальше — ввод полей и клик по кнопке отправки. Приложение будет повторять строку, пока страница не изменится, и остановится, когда изменение появилось.
